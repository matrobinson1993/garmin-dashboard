    How is this private?

    This page talks only to GitHub, straight from your browser. It creates a copy of the dashboard in your GitHub account, stores your Garmin login as GitHub secrets (encrypted in your browser with your repository's public key before sending), and turns on GitHub Pages. The access key is kept only in this browser tab and is never saved.

    Each day GitHub Actions in your account downloads your Garmin data and encrypts it with your passphrase. The published page is public but unreadable without the passphrase; your phone decrypts it. The person who shared this page never sees your logins or data. This uses Garmin's unofficial API and isn't endorsed by Garmin.
